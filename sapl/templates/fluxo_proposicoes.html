Conceitos Fundamentais

Proposição

É a proposta inicial criada pelo parlamentar que ainda não foi oficialmente incorporada ao processo legislativo.

  • Criada pelo parlamentar/autor
  • Pode ser editada antes de enviar
  • Não tramita (não é oficial)
  • Não pode ser votada
  • Possui número sequencial próprio

Matéria Legislativa

É a proposição oficialmente recebida que pode tramitar e ser votada.

  • Criada ao incorporar proposição
  • Possui número oficial (PL nº 1/2025)
  • Tramita entre unidades
  • Pode ser votada em sessão
  • Possui protocolo (se configurado)

Diferença entre Proposição e Matéria Legislativa

Característica Proposição Matéria Legislativa
Status Proposta preliminar Oficialmente incorporada
Tramitação ❌ Não tramita ✅ Tramita entre unidades
Votação ❌ Não pode ser votada ✅ Pode ser votada
Criador Autor (Parlamentar) Operador de Protocolo
Edição Editada pelo autor Editada por operadores autorizados

Atores do Sistema

Parlamentar PARLAMENTAR

Membro eleito da casa legislativa que cria proposições.

  • Possui cadastro completo (dados pessoais, foto, mandatos)
  • Ao ser cadastrado, um Autor é criado automaticamente
  • Precisa de um usuário do sistema vinculado para acessar

Autor

Abstração que representa quem pode criar proposições.

  • Pode ser: Parlamentar, Órgão, Comissão, Cidadão
  • Criado automaticamente ao cadastrar parlamentar
  • Vinculado a usuários através de OperadorAutor

Operador de Protocolo OPERADOR

Responsável por receber e processar proposições.

  • Recebe proposições (via código ou lista)
  • Pode incorporar (transformar em matéria)
  • Pode devolver (com justificativa)
  • Gera protocolos

Permissões Necessárias para Criar Proposições

IMPORTANTE: Requisitos para Acesso

Para que um usuário possa acessar /proposicao/create e criar proposições, ele precisa atender DOIS requisitos obrigatórios:

1. Grupo "Autor"

O usuário precisa estar no grupo "Autor" do sistema.

Como adicionar:

Ir para Usuários

URL: /sistema/usuario/ Acessar

Editar o usuário desejado

Clique no nome do usuário (ex: helena)

Adicionar ao grupo

Na seção "Grupos", marque "Autor"

Clique em "Salvar"

2. Vínculo com Autor

O usuário precisa estar vinculado como operador de um Autor.

Como vincular:

Ir para Editar Usuário

URL: /sistema/usuario/{id}/edit Ver Lista

Selecionar o Autor

No campo "Autor", selecione o autor correspondente (ex: "Helena Silva")

Se não existir autor, crie um parlamentar primeiro

Salvar

Isso cria automaticamente o vínculo OperadorAutor

✓ Pronto! Agora o usuário pode criar proposições.

Exemplo de Erro Comum

Se o usuário helena possui os grupos:

  • Operador Geral
  • Operador de Matéria
  • Operador de Norma Jurídica
  • Votante

Ela NÃO conseguirá criar proposições porque:

  • ❌ Não está no grupo "Autor"
  • ❌ Não está vinculada a nenhum Autor

Solução: Adicionar ao grupo "Autor" E vincular a um Autor existente.

Atalho Rápido

Para vincular rapidamente um usuário e permitir criação de proposições:

  1. Acesse /sistema/usuario/
  2. Clique no usuário desejado
  3. Clique em "Editar"
  4. Marque o grupo "Autor"
  5. No campo "Autor", selecione o autor correspondente
  6. Salve
Ir diretamente para: /sistema/usuario/ Configurar Agora

Estados de uma Proposição

RASCUNHO

Não Enviada

  • Criada mas não enviada
  • Pode ser editada
  • Pode ser excluída
  • Somente autor vê
URL: /proposicao/ Acessar

PENDENTE

Enviada, aguardando recebimento

  • Enviada para protocolo
  • Código de recebimento gerado
  • Autor pode retornar (cancelar)
  • Operador pode receber ou devolver
URL: /proposicao/pendente/ Acessar

DEVOLVIDA

Rejeitada pelo protocolo

  • Devolvida com justificativa
  • Autor pode ver motivo
  • Pode corrigir e reenviar
URL: /proposicao/devolvida/ Acessar

INCORPORADA

Transformada em matéria

  • Matéria legislativa criada
  • Autoria vinculada
  • Protocolo gerado (se configurado)
  • Pode tramitar e ser votada
URL: /proposicao/recebida/ Acessar
